## Provenance

USL-1.0 adapts the QNFO Unified License Agreement v2.1 (<https://github.com/QNFO/license>): the same non-commercial / commercial split, the same share-alike and network-use rules, the same prohibited-use list, the same Swiss-law and ICC-arbitration choice. It differs in four places: a published, self-serve commercial price list (Section 4), a reasonable-royalty remedy for unlicensed use in place of an 85% revenue clause (Section 5), the Specification is covered with an Implementation clause (Section 7), and later versions do not retroactively change a release already received (Section 20).
